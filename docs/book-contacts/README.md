# База контактов книжной индустрии (PROMO.BOOK)

Для приглашения на promo-book.ru издателей, агентов, площадок и партнёров
(ярмарки, премии, магазины, библиотеки). Аналог `docs/radio-contacts-curated-2026.csv`.

## Файлы
- `book_industry_contacts_RU.csv` / `.xlsx` — сводная база по России (в xlsx — лист на категорию).
- `parts/NN_*.csv` — исходные сегменты; сводка пересобирается из них:
  `python3 tools/merge-book-contacts.py docs/book-contacts`
- `BRIEF.md` — правила сбора и формат колонок.

## Правила
- Только публично опубликованные контакты организаций и публичных профессионалов;
  у каждой строки — URL источника и достоверность (высокая / средняя / низкая).
- Перед рассылкой: «средняя»/«низкая» — проверить; общие адреса (АКФ у ~15 фестивалей,
  группа Эксмо/АСТ у ~30 импринтов) — один получатель, письма объединять.
- Личные рабочие адреса сотрудников (редакторы, заведующие отделами) — меняются, перепроверять.
