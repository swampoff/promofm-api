# Бриф: база контактов книжной индустрии России для PROMO.BOOK

PROMO.BOOK (promo-book.ru) — книжная платформа: каталог новинок, хит-парад, еженедельная рассылка
«Новинки недели» для СМИ, блогеров, библиотек и издателей; подборка рукописей для издательств и
литературных агентов; раздел партнёров (ярмарки, премии, магазины, библиотеки). Нужна база B2B-контактов,
чтобы приглашать их на платформу (роли: издатель/агент, площадка, партнёр).

## Правила
- Только ПУБЛИЧНО опубликованные контакты организаций и публичных профессионалов (сайт организации,
  страница «Контакты», официальные соцсети, отраслевые каталоги). Ничего не выдумывать и не угадывать
  e-mail по шаблону. Если e-mail не найден — оставить пустым, но дать сайт/форму/телефон/Telegram.
- Каждую строку подтверждать источником (URL страницы, где найден контакт).
- Предпочитать адреса, релевантные нам: отдел прав / рукописей / PR / маркетинг / закупки / оргкомитет,
  плюс общий info@.
- Достоверность: «высокая» — e-mail увиден на официальной странице организации; «средняя» — из
  стороннего каталога/статьи; «низкая» — косвенно/устарело.
- Без дублей (по организации + e-mail).
- Работать широко: цель — МАКСИМУМ организаций в своём сегменте (ориентир указан в задаче). Сначала
  найти списки/каталоги (рейтинги, участники ярмарок, члены ассоциаций, Википедия), затем пройтись по
  сайтам. Использовать WebSearch и WebFetch (через агент web-fetch, если нет своего WebFetch).
- Записывать промежуточный результат в файл регулярно (каждые ~20 строк), чтобы работа не пропала.

## Формат вывода — CSV, UTF-8, все поля в двойных кавычках, первая строка — заголовок:
"Категория","Подкатегория","Организация","Контактное лицо","Должность","Город","Регион","Сайт","Email","Email доп.","Телефон","Соцсети/Telegram","Достоверность","Источник","Примечание"

Категории (ровно одно из): Издательство | Литературный агент | Ярмарка/фестиваль | Премия/конкурс |
Книжный магазин/сеть | Онлайн-платформа | Библиотека | СМИ/медиа | Блогер/подкаст | Ассоциация/институт |
Образование/школа | Услуги для авторов | Дистрибуция/типография
