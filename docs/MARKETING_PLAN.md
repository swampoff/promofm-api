# Маркетинг-план ПРОМО.МУЗЫКА — автоматическая машина продвижения

Составлен 2026-07-08 по инвентаризации ВСЕЙ существующей машинерии
кода. Принцип: **каждый день платформа продвигает себя сама, по
крону** — люди принимают решения (вычитка, decision-needed, бюджеты),
роботы делают всё остальное. Времена — МСК.

---

## 1. Стратегия одним абзацем

Два маховика, связанные общим предложением. **Маховик спроса
(заведения)**: SEO-посадочные под все сегменты + болевой кластер
РАО/ВОИС + статьи 2×/день → заявки на подписку «легальная музыка для
бизнеса». **Маховик предложения (креаторы)**: артисты, диджеи,
продюсеры, лейблы несут контент в каталог, потому что это офлайн-промо
и роялти («трек играет в кафе» — голубой океан, конкурентов в выдаче
нет). Каждая аудитория заходит через свой информационный запрос
(статья) → фраза-ссылка → профильный раздел → кабинет. Indoor-реклама
монетизирует стык. РАО/ВОИС — общий крючок всей системы: заведению —
защита от штрафа, креатору — легальный доход.

## 3. Единое суточное расписание (целевое)

```
каждые 5 мин   email-campaigns тикер (отправка порций кампаний)
каждые 15 мин  reconcile fingerprints (треки + миксы)
каждый час     banner rotation
06:00          charts-agent: обновление чартов станций
09:00          analytics-daily-report → info@ (вчерашние цифры)
10:00          ★ article-agent: статья №1 (аудитория N)
10:00          radio-digest: новинки радио-партнёрам
12:00 / 18:00  prerender.py (6ч): снапшоты статичных + 40 статей
18:00          ★ article-agent: статья №2 (аудитория N+1)
ночь           videos/concerts агенты, sla-sweep (6ч), news-agent fetch
```

## 7. Разрывы — чего машине не хватает (бэклог по приоритету)

### P1 — включается за один заход
1. **Включить article-agent** (issue #300: 2 cron-строки + вычитка
   первых статей глазами). Без этого главный контент-конвейер стоит.
2. **Крон-карта → одно место**: сверить фактический crontab VPS с
   разделом 3 (laptop; расхождения → в этот файл).
3. **Базовая линия индексации** (site: до/после — issue #298 п.3).

### P2 — недельный горизонт
4. **TG-канал платформы с автопостингом**: каждая опубликованная
   статья/новость → пост в канал (у нас уже есть notifyAdminTelegram —
   тот же Bot API, другой chat_id; ~50 строк в article/news-agent).
   Канал = бесплатный ретеншн-канал для креаторов.
5. **Email-nurture цепочки** на базе email-campaigns: welcome-серия
   по роли (артист → 3 письма: как опубликовать / как попасть в эфир /
   как заработать; venue → штрафы / подключение / реклама в эфире).
   Сегменты уже умеет; нужен триггер «дни после регистрации».
6. **Автообновление external-clips** (сейчас ручная еженедельная
   задача — videos-agent уже парсит источники, расширить).
7. **RSS-фид /news/rss.xml** — дистрибуция статей в агрегаторы
   (Яндекс.Дзен/Пульс кандидаты) + подписчики.

### P3 — по решению Никиты (decision-needed, копятся в SEMANTIC_CORE §17–19)
8. Гео-страницы Москва/СПб/Сочи (нужна честная база заведений).
9. Брендовый перехват («альтернатива fonmix/бубука/distrokid/Epidemic»)
   — юридически/репутационно чувствительно.
10. Офферные LP «Сеты в заведениях» (DJ) и «Сдай инструментал»
    (продюсеры) — когда появится цифра реальной базы точек.
11. База инди-лейблов + адресный питч лицензирования (не SEO-канал).
12. Платный трафик (Директ/РСЯ на /legal-music и сегментные LP) —
    только после того, как органика покажет конверсию LP → заявка.
