# PROMO.AIR landing

Полная адаптивная версия лендинга PROMO.AIR: собственное радио, фоновая музыка и аудиобрендинг для заведений.

## Live

https://promo-air-explore.fairbetta16.chatgpt.site

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка сборки

```bash
npm run build
```

Исходники лендинга изолированы в этой директории и не меняют существующий API-проект в корне репозитория.
