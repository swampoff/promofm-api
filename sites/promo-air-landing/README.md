# PROMO.AIR website package

Актуальный многостраничный frontend PROMO.AIR из опубликованного дизайн-проекта.

## Локальный запуск

```bash
python3 -m http.server 8080 --directory dist
```

Основные маршруты:

- `/promo-air/` — маркетинговый сайт и страницы направлений;
- `/app/` — визуальный прототип мобильного приложения;
- `/cabinet/` — адаптивный кабинет владельца заведения;
- `/admin/` — административный frontend-прототип.

## Важно

Кабинет, приложение и админка используют локальные демонстрационные данные. Они не заменяют существующие авторизацию, API, биллинг, роли и управление устройствами. Перед подключением к production начните с `handoff/START_HERE.md` и соблюдайте границы интеграции из остальных файлов в `handoff/`.
