# PROMO.AIR: передача в Codex

Дата: 15.10.2026. Дизайн: Promo.Art.

## Задача
Перенести готовый визуальный слой из dist в действующий frontend promo-music.ru, сохранив существующие авторизацию, кабинеты, API, биллинг, роли и маршруты. Не создавать новую платформу и не заменять существующий backend.

## Входные данные
- dist/: полная работающая статическая концепция, изображения, четыре аудиоэскиза, CSS, JS и метаданные.
- dist/integration.md: история решений и ограничения.
- dist/pricing.json: маркетинговые цены из опубликованного frontend на 15.10.2026. Это НЕ биллинговый источник.
- handoff/SEO_ROUTES.json: URL, title, description для переноса.
- handoff/sitemap.production.xml: подготовленная карта продакшн-маршрутов. Разместить только после запуска реальных страниц.
- handoff/IMPLEMENTATION.md: последовательность интеграции и проверка.

## Неизменяемые требования
1. Основной маршрут /promo-air. /promoair может быть только согласованным алиасом.
2. Пробный период: 7 дней без оплаты.
3. Подпись Design by Promo.Art на всех страницах.
4. Nico лысый, в очках и оранжевых наушниках. Sandra: кофейни, Leo: бары, Mia: wellness. Стиль: коллекционные виниловые фигурки, светлые миниатюрные пространства, мягкое стекло и хром.
5. Палитра #73C9FF, #FF691F, #F9FCFF, #162538, #C9B7FF, #A8EEDC. Unbounded + Manrope.
6. Существующие вход/оплата остаются в приложении. Не добавлять фиктивные endpoint, токены и платежные формы.
7. Текущий Site приватный. Нельзя менять аудиторию или публиковать на основной домен без соответствующего доступа.

## Что уже работает в концепции
- HTMLAudio: play/pause, 4 аудиоэскиза, громкость, переключение, ошибки загрузки, время.
- Анимации винила, тонарма, индикатора только в состоянии воспроизведения; reduced-motion.
- Свайп карточек на мобильных, scroll-snap, счетчик, стрелки клавиатуры на контейнере.
- Месячные и годовые цены, переключаемые на клиенте.
- Сценарий расписания в localStorage, локальный пример зон, текстовый пример приветствия.

## Чего пока нет
Это не серверный кабинет. Нет реального управления эфиром, сохранения расписания в БД, оплаты, авторизации, загрузки джинглов, реальных потоков, live-метаданных и управления устройствами. Аудиоэскизы нельзя выдавать за каталог сервиса. В демонстрации не обещать фактическое применение настройки к заведению.

## Запуск
Для локального просмотра достаточно python3 -m http.server 8080 --directory dist. Для продакшн перенести в существующий React/router проект. Для текущего Sites используется статическая сборка без зависимостей.
