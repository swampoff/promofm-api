# Интеграция и критерии готовности

## 1. Разведка репозитория
Прочитать AGENTS.md, package.json, router, auth providers, роль venue, тарифный loader, player context и схемы backend. Найти действующие обработчики вместо создания дубликатов. Зафиксировать текущую ветку и незакоммиченные изменения.

## 2. Компоненты
Выделить Header/Footer, Hero, CharacterCard, SwipeRail, VenueGallery, AudioPlayer, ScheduleEditor, ZonePanel, PricingSection, RightsSection. CSS сейчас layered: styles.css, pages.css, polish.css, universe.css, refine.css. При переносе объединить в токены/компоненты без смены вида. Учитывать специфичность и media rules. Сохранять пропорции atlas 2x2 и world atlas 3x2.

## 3. Подключения
- Auth: существующий /login и восстановление сессии.
- Тарифы: получать id, currency, billing interval, price, limits из действующего billing API. Вызов checkout только существующий. Сервер проверяет доступность пробного периода, не браузер.
- Плеер: действующий player context и разрешённый поток; signed URL получать серверно. Состояния loading/playing/paused/error/offline; autoplay только после жеста пользователя. При смене трека отменять устаревшие play promises. При навигации согласовать единый экземпляр audio.
- Метаданные: использовать реальный now-playing источник; имена демонстрационных подборок не считать названиями реальных треков.
- Расписание: заменить localStorage на существующий tenant-scoped API, часовой пояс заведения, проверку пересечений и подтверждение сохранения. Не создавать endpoint по предположению.
- Зоны: tenant/venue/zone ACL на сервере, контроль соединения устройства и подтверждение применения громкости.
- Джинглы: существующая загрузка, модерация, права доступа; фиксировать статус и ошибки.

## 4. Цены и права
Маркетинговые константы опубликованного public-pages-CLObek7_.js: Старт 4990/49900, Бизнес 9990/99900, Сеть 14990/149900, Радио полного цикла 20000/200000 RUB (месяц/год). Биллинг может отличаться; после интеграции он единственный источник. НДС/дополнительные услуги не предполагать.

Фраза «без РАО и ВОИС» допустима только для документально подтверждённого режима каталога. Прямое разрешение на произведение не автоматически закрывает вознаграждение по смежным правам. До безусловного рекламного обещания проверить цепочку прав на каждое произведение/исполнение/фонограмму, статус коллективного управления, территорию и способ использования. Текущий текст раскрывает условия, не обещает освобождение для любой музыки.
Источник проверки: https://rao.ru/poryadok-ispolzovaniya/ . Не переносить старые численные штрафы с других страниц.

## 5. SEO
Каждый маршрут имеет уникальные title/description, canonical на основной домен, Open Graph и WebPage JSON-LD. Во временной концепции сохранены noindex и robots Disallow. При реальном запуске снять их ТОЛЬКО на нужных продакшн-страницах, подключить подготовленную sitemap, добавить реальный абсолютный og:image, серверный рендер или prerender и правильные HTTP-статусы. Не индексировать приватные кабинеты.
Справочники canonical и sitemap без завершающего слеша; настроить единую политику редиректов. Главную концепции не переносить в корень всего promo-music.ru.
Не добавлять Offer/AggregateRating и другие неподтверждённые данные. FAQ-разметка только для видимых реальных вопросов и ответов.

## 6. Проверки перед релизом
- 360, 390, 768, 1280 и 1440 px: изображения без растяжения; без горизонтального overflow страницы, кроме swipe rails.
- iOS Safari / Android Chrome: свайп не мешает вертикальному скроллу, ссылки нажимаются, звук запускается жестом.
- Клавиатура: видимый фокус, доступ ко всем карточкам, controls имеют имена, reduced motion.
- Месяц/год показывает полную сумму годового платежа, не подменяет её месячным эквивалентом.
- Реальные happy/error paths: auth, checkout, пробный период, поток, расписание, зоны. Между организациями нет доступа.
- Цены совпадают с checkout, права соответствуют договору.
- Выполнить проектные проверки и сборку; текущая концепция проверена по JS-синтаксису и локальным ссылкам. Браузерная визуальная QA в текущей среде недоступна.
